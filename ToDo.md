# Verwaltungsprogramm mit Web-Oberfläche
### Erstelle analog zur Aufgabe 7 ein Verwaltungsprogramm für Objekte deiner Wahl. Die Objekte werden in einer MySQL-Datenbank gespeichert.

1. Die Applikation soll eine Web-Oberfläche haben.

Folgende Funktionalitäten sollen realisiert werden:

* Daten für ein neues Objekt eingeben und Objekt speichern
* Alle vorhandenen Objekte in einer Tabelle anzeigen
* Ein bestehendes Objekt löschen
* Ein bestehendes Objekt aktualisieren
