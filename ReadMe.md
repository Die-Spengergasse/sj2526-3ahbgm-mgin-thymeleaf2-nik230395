# Patientenverwaltung

Eine einfache Webanwendung zur Verwaltung von Patientendaten, gebaut mit Spring Boot und Thymeleaf.

## Was die App kann

- Patienten anlegen, bearbeiten und löschen
- Alle Patienten in einer Liste anzeigen
- Liste seitenweise blättern (Pagination)
- Nach Geburtsdatum sortieren (auf- und absteigend)

#### Starten und dann im Browser: `http://localhost:8080/patients`
